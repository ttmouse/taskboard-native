# 架构要点

## 数据与作用域

- 应用自有数据层（SQLite 种子 → 本地服务权威）。
- **项目作用域查询**：代理可被限定只看项目 A 的任务（API/`projectId` 与 MCP 过滤一致）。
- 全局「local」与各 workspace 项目并存。

## 界面

- **全程 MyGo 原生 UI**（非 WebView 壳）。
- 聊天气泡：**主机 → 深链映射表**（展示与跳转配置），与看板列同步解耦；深链实现另卡跟踪。

## 代理接口

- **CLI** 与 **MCP**：创建/更新/移动/评论；写操作带 version 与代理身份头（对齐现有 dsh-taskboard 约定）。
- 任何 CLI/MCP 写入必须触发实时推送（见 realtime-sync.md）。

## 体积与性能

- 安装包与常驻内存对标 **PULSE**：尽量小二进制、低空闲占用；后台不忙时不轮询、不空转定时器。
