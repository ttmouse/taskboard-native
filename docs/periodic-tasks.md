## Agent 约定

1. **启动时**：读本文件；若看板有「周期任务表」卡，以卡上最新正文为准（卡可被人工更新）。
2. **到点**：只跑表内启用行；不要发明未登记的周期活。
3. **写回**：在「周期任务表」卡下评论一行：`[周期] <名称> <Asia/Shanghai 时间> <结果摘要>`。
4. **禁止**：把一次性需求写成隐式周期；改时刻/启停须先改本表与看板卡。

## 与 Grok Bot 例程的关系

表中「Grok Bot 例程」对应豆皮侧 `UpdateRoutine` 保存的自动化。例程 prompt 应引用本表或看板卡 ID，避免双源漂移。
