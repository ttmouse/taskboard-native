## 现状与证据

saveUIPrefs correctly returns filesystem failures from directory creation, temporary file write, and rename. Project sort, sidebar collapse, Git preference, and many view settings discard that error. If the preferences directory becomes unwritable or disk IO fails, the current UI changes but silently revert on restart.

## 建议方向

Centralize preference persistence feedback: retain the live in-memory selection but show one actionable notice when saving fails, with a retry route or clear indication that the change was not persisted. Avoid emitting repeated toasts from frame-driven paths.

## 验收标准

Inject a prefs-path write or rename failure for each save entry class; the UI reports that the setting is session-only/not saved and provides retry or a clear recovery action. Successful saves remain quiet and survive restart; repeated render frames do not flood notifications.

补充异步写入路径（2026-11-04）：toggleSidebarForCase 为 ⌘B/侧栏图标操作调用 saveUIPrefsAsync（cmd/taskboard/view.go:1055-1069）；saveUIPrefsAsync 的单后台 writer 在 prefs.go:238-243 对 saveUIPrefsAt 返回值直接忽略，调用者也没有结果回调。目录创建、临时文件写入、rename 失败时，侧栏状态只在当前进程生效且没有用户提示。该路径与同步设置 handler 静默丢弃 saveUIPrefs 错误根因相同；验收需覆盖异步写入失败及队列合并后最新状态的可诊断反馈。

补充退出时队列未 flush（2026-11-04）：toggleSidebarForCase 将唯一的异步偏好变更写入容量为 1 的 uiPrefsAsyncQueue 后立即返回；后台 worker 无 done/flush API，main.runWindow 退出路径只调用 b.stop 与服务关闭，没有等待偏好写入完成（cmd/taskboard/prefs.go:230-258; cmd/taskboard/view.go:1055-1069; cmd/taskboard/main.go:147-155）。用户切换侧栏后快速关闭最后窗口，进程可能在 writer 完成原子 rename 前退出，最后的 SidebarCollapsed 值丢失。验收应在有待写快照时触发正常退出，关闭返回前 flush/等待有限时长并验证重启恢复最后状态；仍保持 UI 点击不等待磁盘 I/O。
