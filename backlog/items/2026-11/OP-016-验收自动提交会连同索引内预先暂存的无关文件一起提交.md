## 现状与证据

项目级“完成时自动 Git 提交”在用户验收完成后运行。函数仅用 add -u 更新已跟踪文件，但不隔离提交范围或保护调用前已有 index entries。Git 提交范围因此由整个 index 决定，而非仅由本次自动暂存操作决定。

## 建议方向

在自动提交前明确提交边界：避免提交调用前已有的索引变更，或在启用自动提交时先拒绝非预期 staged changes 并向用户清晰报告。不要静默重置/覆盖用户 index。增加临时 Git 仓覆盖已有 staged 新增与修改文件。

## 验收标准

仓库预先存在 staged 新文件和 staged 无关修改时，自动完成任务不得把它们带入自动提交；跟踪工作区变更仍可按约定提交，原有 staged 状态完整保留；验证提交内容和 index 前后状态。
